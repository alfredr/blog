{#- Shared template macros. -#} {#- The dates of a CV entry or role, printed with `format` (see data/cv.toml): a range from `start` to `end` joined by `sep`, or a single `date`, which may be a list. A range whose ends print the same collapses to one date, so a years-only label for June to August 2025 is just "2025". -#} {% macro dates(item, format, sep=" - ", present="Present") -%} {%- if item.start -%} {%- set first = item.start | datefmt(format=format) -%} {%- set last = item.end | datefmt(format=format, present=present) -%} {%- if first == last %}{{ first }}{% else %}{{ first }}{{ sep }}{{ last }}{% endif -%} {%- else -%} {{- item.date | datefmt(format=format) -}} {%- endif -%} {%- endmacro dates %} {#- A CV date in the timeline column, with the full date (after an optional `prefix`) on hover. `repeat` marks a label already shown above in the section: it stays in the text (for copying and screen readers) but the timeline shows only its dot. -#} {% macro date(label, full, prefix, repeat) -%} {{ label }} {%- endmacro date %}
